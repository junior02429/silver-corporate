# Silver Corporate

Site officiel de **Silver Corporate**, structure mère à vocation entrepreneuriale basée à Pointe-Noire, République du Congo.

**Former • Inspirer • Transformer**
*Des besoins réels aux solutions concrètes.*

## Contenu du site

- Présentation de Silver Corporate
- Jeunes Inspirés : programme jeunesse
- Silver Services : services administratifs, bureautiques et numériques (tarifs 2026, packs, commande)
- Projets, réalisations, actualités
- Équipe, partenaires, documents

## Mettre à jour le contenu

Les tarifs, packs, projets, actualités, équipe et partenaires se modifient dans le fichier `js/data.js`.
